## 🚨 If Issues Occur

**Minor Issues** (< 2% error rate):
1. Assess severity
2. Check logs: `pm2 logs attendex-backend`
3. Try fix in production
4. Monitor for 30 minutes
5. Escalate if not resolved

**Critical Issues** (> 5% error rate or security issue):
1. Notify team immediately
2. Check database: `mongosh`
3. Execute rollback (see DEPLOYMENT_QUICK_START.md)
4. Investigate root cause
5. Post-incident retrospective

**Rollback Command**:
```bash
git checkout HEAD~1
npm run build
pm2 restart attendex-backend
```
