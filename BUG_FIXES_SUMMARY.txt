================================================================================
PERFORMANCE METRICS
================================================================================

Face Detection:
  - Per frame: 200-400ms (TensorFlow.js in browser)
  - Model load: 1-2s (cached after first load)
  - Multiple faces: Rejected if >1 detected

Descriptor Comparison:
  - Euclidean distance: <1ms
  - API response: 50-100ms (depends on network)
  - Database lookup: 10-20ms

Overall Flow:
  - Registration (3 captures): 2-3 seconds
  - Verification (1 capture): 1-2 seconds


================================================================================
KNOWN LIMITATIONS
================================================================================

1. No Liveness Detection
   - Vulnerable to photo/mask attacks
   - Mitigated by: Session-specific QR codes
   - Fix: Phase 2

2. No Multi-face Support
   - Only processes single detected face
   - Design decision for security

3. CDN Dependency
   - Face API models loaded from CDN
   - Fallback: Custom REACT_APP_FACE_API_URL

4. Browser Compatibility
   - Requires MediaDevices API (all modern browsers)
   - Requires WebGL (for TensorFlow.js)
   - Tested: Chrome, Safari, Firefox, Edge
