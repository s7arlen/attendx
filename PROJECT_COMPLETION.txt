TROUBLESHOOTING QUICK REFERENCE
================================================================================

Port 4000 Already in Use?
  → Run: .\START_APP.ps1 (handles cleanup)
  → Or: Get-NetTCPConnection -LocalPort 4000 | Stop-Process -Force

Frontend Shows Blank?
  → Check: Browser F12 → Console for errors
  → Verify: Backend running (http://localhost:4000/health)
  → Restart: .\START_APP.ps1

Cannot Connect to MongoDB?
  → Check: Get-Process mongod
  → Test: mongosh --eval "db.stats()"
  → Start: MongoDB service if not running

Dependencies Missing?
  → Run: cd backend && npm install && npm run build
  → Run: cd frontend && npm install
